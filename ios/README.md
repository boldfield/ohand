# Oh And iOS

Native iOS application and probe components for Oh And M1.

## Architecture

The iOS project implements:
- **OhAndApp**: Main production application with minimal SwiftUI interface
- **OhAndCore**: Swift framework for core bridge to Rust (generated by P01)
- **OhAndServices**: Services framework for concurrent native task implementations
- **Probe applications**: Isolated validation targets for M1 feasibility testing

## Reproducible Build System

This project uses **XcodeGen** to generate a fully reproducible Xcode project from `project.yml`. This ensures that clean checkouts generate identical project structures and build settings.

### Generate Project

```bash
xcodegen generate
```

This creates `OhAnd.xcodeproj` from `project.yml`. The generated project is not committed to the repository.

### Build for Simulator

```bash
xcodebuild -project OhAnd.xcodeproj \
  -scheme OhAndApp \
  -configuration Debug \
  -sdk iphonesimulator \
  -derivedDataPath .derived
```

See [BUILD.md](BUILD.md) for complete build documentation.

## Project Structure

```
ios/
  Sources/
    App/          # Main application (OhAndApp target)
    Core/         # Framework skeleton for Rust bindings (P01)
    Services/     # Services framework (extensible by M1 tasks)
  Probes/
    BridgeProbe/          # Rust-Swift boundary validation (P01)
    NotificationProbe/    # Native notification scheduling (P05)
    AudioProbe/           # Audio capture and recovery (P03)
    TranscriptionProbe/   # On-device transcription (P04)
    CredentialProbe/      # Keychain credential protection (P11)
    CaptureProbe/         # System control handoff (P02)
  project.yml   # XcodeGen configuration (reproducible)
  BUILD.md      # Build documentation
  .gitignore    # Excludes generated projects and build artifacts
```

## Signing

**Unsigned simulator builds** require no configuration and are the default:

```bash
xcodebuild -project OhAnd.xcodeproj -scheme OhAndApp -sdk iphonesimulator
```

**Device builds** require signing credentials supplied at build time:

```bash
xcodebuild -project OhAnd.xcodeproj -scheme OhAndApp \
  -sdk iphoneos \
  CODE_SIGN_IDENTITY="iPhone Developer" \
  DEVELOPMENT_TEAM="ABCD1234567"
```

No certificates, provisioning profiles, or team IDs are committed to the repository.

## Module Ownership

Ownership is enforced by directory-based source inclusion in `project.yml`:

| Module | Purpose | Task |
| --- | --- | --- |
| `Sources/App/` | Main application UI (SwiftUI) | (M1 shell after P10) |
| `Sources/Core/` | Swift framework for bindings | P01 (generates), B01 (maintains) |
| `Sources/Services/` | Services composition framework | B02 (owns) |
| `Probes/BridgeProbe/` | Rust-Swift boundary probe | P01 |
| `Probes/NotificationProbe/` | Notification scheduling probe | P05 |
| `Probes/AudioProbe/` | Audio capture probe | P03 |
| `Probes/TranscriptionProbe/` | Transcription probe | P04 |
| `Probes/CredentialProbe/` | Keychain credential probe | P11 |
| `Probes/CaptureProbe/` | System control handoff probe | P02 |

Concurrent tasks add implementations to their owned directories without editing `project.yml`.

## Deployment Target and SDK

- **iOS Deployment Target**: 16.0
- **iOS SDK**: 15.4
- **Swift**: 5.9
- **Xcode**: 15.4

Editable in `project.yml` `options.deploymentTarget` and `options.xcodeVersion`.

## Generated Project

The Xcode project (`OhAnd.xcodeproj`) is **generated** and not committed. Regenerate after editing `project.yml`:

```bash
xcodegen generate
```

Do not manually edit the generated Xcode project settings.
